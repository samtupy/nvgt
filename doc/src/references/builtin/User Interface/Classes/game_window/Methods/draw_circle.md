# draw_circle
Draw a circle.

`void game_window::draw_circle(float cx, float cy, int radius, uint r, uint g, uint b, bool filled = false);`

## Arguments:
* float cx: the horizontal position of the center.
* float cy: the vertical position of the center.
* int radius: the radius.
* uint r: the red component of the color, from 0 to 255.
* uint g: the green component of the color, from 0 to 255.
* uint b: the blue component of the color, from 0 to 255.
* bool filled = false: whether to fill the circle rather than only drawing its outline.
