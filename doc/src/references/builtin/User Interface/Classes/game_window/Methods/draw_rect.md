# draw_rect
Draw a rectangle.

`void game_window::draw_rect(float x, float y, float w, float h, uint r, uint g, uint b, bool filled = false);`

## Arguments:
* float x: the horizontal position of the top left corner.
* float y: the vertical position of the top left corner.
* float w: the width.
* float h: the height.
* uint r: the red component of the color, from 0 to 255.
* uint g: the green component of the color, from 0 to 255.
* uint b: the blue component of the color, from 0 to 255.
* bool filled = false: whether to fill the rectangle rather than only drawing its outline.
