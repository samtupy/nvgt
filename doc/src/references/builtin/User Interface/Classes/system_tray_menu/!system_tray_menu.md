# system_tray_menu
The menu of a system_tray icon, or a submenu of it, holding items, checkboxes, submenus and separators.

## Remarks:
Menus can't be created directly. The menu of a tray icon comes from system_tray::menu, and a submenu from the submenu property of an item inserted with insert_submenu(). See system_tray for an example.
