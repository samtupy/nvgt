# get_string_size
Measure a line of text.

`bool text_font::get_string_size(const string&in text, int&out w, int&out h) const;`

## Arguments:
* const string&in text: the text to measure.
* int&out w: receives the width in pixels.
* int&out h: receives the height in pixels.

## Returns:
bool: true on success, false otherwise.
