# get_dpi
Get the display resolution the font's size is for.

`bool text_font::get_dpi(int&out hdpi, int&out vdpi) const;`

## Arguments:
* int&out hdpi: receives the horizontal resolution in dots per inch.
* int&out vdpi: receives the vertical resolution in dots per inch.

## Returns:
bool: true on success, false otherwise.
