# get_color_mod
Get the color that is multiplied with the image when it is drawn.

`bool graphic::get_color_mod(uint&out r, uint&out g, uint&out b) const;`

## Arguments:
* uint&out r: receives the red component.
* uint&out g: receives the green component.
* uint&out b: receives the blue component.

## Returns:
bool: true on success.
