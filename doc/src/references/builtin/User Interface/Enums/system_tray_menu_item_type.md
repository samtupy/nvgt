# system_tray_menu_item_type
The possible types of a system_tray_menu_item.

* SYSTEM_TRAY_ITEM: an item that runs its callback when chosen.
* SYSTEM_TRAY_CHECKBOX: an item that can be checked or unchecked.
* SYSTEM_TRAY_SEPARATOR: a separator line between items.
* SYSTEM_TRAY_SUBMENU: an item that opens a submenu.
