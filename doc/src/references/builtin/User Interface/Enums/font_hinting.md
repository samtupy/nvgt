# font_hinting
Ways of adjusting the outlines of glyphs to the pixel grid. No method of text_font takes these values at this time.

* FONT_HINTING_NORMAL: normal hinting.
* FONT_HINTING_LIGHT: lighter hinting, which keeps the shapes of glyphs closer to their design.
* FONT_HINTING_MONO: strong hinting for text drawn without smoothing.
* FONT_HINTING_NONE: no hinting.
* FONT_HINTING_LIGHT_SUBPIXEL: light hinting for subpixel rendering.
