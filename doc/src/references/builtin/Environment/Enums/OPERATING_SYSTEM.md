# OPERATING_SYSTEM
This is a list of possible values of the `OS` property. Many of these exist for completeness, since NVGT itself only runs on a few of these systems.

* OS_WINDOWS_NT: any version of Windows.
* OS_LINUX: Linux.
* OS_DARWIN: macOS or iOS.
* OS_ANDROID: Android.
* OS_FREE_BSD: FreeBSD.
* OS_NET_BSD: NetBSD.
* OS_OPEN_BSD: OpenBSD.
* OS_CYGWIN: Cygwin.
* OS_SOLARIS: Solaris.
* OS_AIX: AIX.
* OS_HPUX: HP-UX.
* OS_TRU64: Tru64.
* OS_IRIX: IRIX.
* OS_QNX: QNX.
* OS_VXWORKS: VxWorks.
* OS_NACL: Native Client.
* OS_VMS: OpenVMS.
* OS_UNKNOWN_UNIX: a Unix like system that isn't otherwise listed.
