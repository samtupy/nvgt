# ARCHITECTURE
This is a list of possible values of the `PROCESSOR_ARCHITECTURE` property. Many of these exist for completeness, since NVGT itself is only built for a few of these architectures.

* ARCH_AMD64: 64 bit x86 processors from Intel and AMD, also called x64.
* ARCH_IA32: 32 bit x86 processors.
* ARCH_ARM64: 64 bit ARM processors.
* ARCH_AARCH64: another name for ARCH_ARM64, with the same value.
* ARCH_ARM: 32 bit ARM processors.
* ARCH_IA64: Intel Itanium.
* ARCH_PPC: PowerPC.
* ARCH_POWER: IBM POWER.
* ARCH_MIPS: MIPS.
* ARCH_SPARC: SPARC.
* ARCH_ALPHA: DEC Alpha.
* ARCH_HPPA: HP PA-RISC.
* ARCH_M68K: Motorola 68000.
* ARCH_S390: IBM System/390.
* ARCH_SH: SuperH.
* ARCH_NIOS2: Nios II.
* ARCH_RISCV64: 64 bit RISC-V.
* ARCH_RISCV32: 32 bit RISC-V.
* ARCH_LOONGARCH64: 64 bit LoongArch.
