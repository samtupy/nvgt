# mail_priority
The priorities of a mail_message, set with mail_message::set_priority().

* MAIL_PRIORITY_HIGHEST: 1, the highest priority.
* MAIL_PRIORITY_HIGH: 2, high priority.
* MAIL_PRIORITY_NORMAL: 3, normal priority, which messages have if none is set.
* MAIL_PRIORITY_LOW: 4, low priority.
* MAIL_PRIORITY_LOWEST: 5, the lowest priority.
