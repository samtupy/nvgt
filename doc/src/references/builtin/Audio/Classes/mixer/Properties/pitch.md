# pitch
The pitch and speed of everything in the mixer.

`float mixer::pitch;`

## Remarks:
In the default engine this is a percentage where 100 is normal, 50 is half speed and an octave lower and 200 twice the speed and an octave higher. In an engine you create it is a multiplier where 1 is normal. A mixer's pitch multiplies the pitches of the sounds in it.
