# t60
The time in seconds that the reverb takes to die away by 60 decibels, between 0 and 100.

`float audio_fdn_reverb_node::t60;`

## Remarks:
The default is 0.3. This is the usual measure of how long a room rings, from around 0.3 seconds for a furnished room to several seconds for a cathedral or a cave. It applies to the middle frequencies, with `lf_rolloff` and `hf_rolloff` changing it for the lows and highs.
